Put LSDJ 9.4.0 .sav files here (up to 64, directly in this folder, no sub-folders).
On the TABLE page pick one with Import File, then tap Import Now. It replaces all 16 tables
and 16 waves (the first 16 tables in the file, waves 0-15). Import Undo restores the
previous content; Import Scan re-reads this folder after you add files.
